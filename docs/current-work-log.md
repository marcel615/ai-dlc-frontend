## 기록 원칙

- 실제 수행한 작업과 확인된 결과만 기록한다.
- 승인된 범위와 예외 사항을 명확히 남긴다.
- 실행하지 않은 검증은 성공으로 표시하지 않는다.
- PR Merge는 사용자가 직접 진행한다.
